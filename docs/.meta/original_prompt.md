基于Go语言实现一个极客敏捷量化时间看板与里程碑燃尽图系统（Mini Pomodoro Scrum）

业务背景：这是一款面向独立开发者、自由职业者或小团队的量化时间管理与敏捷项目追踪平台。它不只让你死板地记录任务，而是把每一个待办任务（Task）或里程碑（Milestone）都量化为具体的"番茄钟预估数"。通过你每天真实专注敲完的番茄钟，系统在后台动态调整并渲染出整个项目的实时燃尽图（Burn-down Chart），量化你的工作效率。

前端页面 (Vue 3 / React + TailwindCSS + Echarts + WebSocket)：
- 敏捷看板与里程碑视图：左侧展示里程碑（如：2月底完成 V1.0 核心网关开发），中间是标准 Kanban，卡片上显示预估番茄数（例如：预计耗费 5 🍅）。
- 极客沉浸式番茄钟：全屏/大卡片倒计时（25分钟），支持白噪音切换。番茄钟运行、暂停、放弃时，页面会有流畅的动效。
- 动态燃尽图大屏：利用 Echarts 渲染。包含两条线：理想燃尽线（任务按时完成的理想状态）和真实燃尽线（后端根据你每天成功结算的番茄钟，动态计算并更新剩余工作量，实时波动的曲线）。

Go 后端核心实现：
- 高并发番茄钟状态机（Pomodoro State Machine）：这是后端的硬核部分。番茄钟有 Idle（空闲）、Running（专注中）、Paused（暂停）、Completed（已完成）、Aborted（已放弃）五种状态。后端需用 Go 的锁机制或状态机模式，严密校验状态翻转（例如：不能直接从 Idle 变成 Completed），并处理由于网络断开导致的"异常流产"逻辑。
- WebSocket 状态保活与心跳：前端番茄钟在倒计时，后端也必须在内存中维持该 Session 的倒计时，利用 WebSocket 实时同步，防止用户刷新网页后计时丢失。
- 时序燃尽数据聚合引擎：当一个绑定了某个里程碑的任务被结算（消耗了番茄钟或被标记为完成）时，后端异步触发事件（Event），实时重新计算该里程碑的剩余总点数，并将带时间戳的数据写入持久化层，供前端绘制燃尽图。

文件数与代码量：约 32+ 个 Go 文件，代码量 6000 - 8500 行。
